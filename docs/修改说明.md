


## 云服务器可视化图片保存失败 260828

哈希：`fa64c8f88479c6046cbc2420d04769b4363f828a`
修改原因：
- `offscreen=True` 为 Unreal 添加 -RenderOffScreen，这个选项适配适配云服务器，因为没有图形界面。
- `render=True` RescueBench 在评估时保存 latest_frame.jpg 和历史帧，方便进行可视化分析。
- 两者在官方源码中是不兼容的，因此修改后使得两个设置可以同时使用。

## 添加指定测试点的评估

哈希：`42edd79c756220339a012e273a254f569210033d`
修改原因：
- 源代码没有指定测试点评估的功能，导致每次评估都需要对整个数据集的某个level进行评估，耗时较长。
- 指定使用某个模型对某个单独的测试点进行测试
- 这样我可以直接对整体进行无渲染的测试，而只对感兴趣的测试点进行可视化。
